# Feature catalog

| Capability | P0 | P1 | P2/platform |
|---|---|---|---|
| Learn | path, two missions, skills | boosters, more packs | adaptive curricula/locales |
| Investigate | curated evidence actions | live academic/fact-check/provenance adapters | bounded open-web workspace |
| Coach | Socratic hint ladder/fallback | personalized difficulty | studied adaptive coach |
| Judge/reflect | three axes, uncertainty, confidence/share | richer evidence graph | research/teacher rubrics |
| Motivate | process XP, compassionate streak, progress | achievements/daily booster | optional friends/community, no political leaderboard |
| Receipt | reproducible learning record | correction notification | privacy-safe export/integration |
| Content | checked-in reviewed fixtures | pack validation/publishing tool | editorial CMS, localization, partner workflow |
| Education | printable pack mock | assignment code/cohort aggregate | workspace/LMS/SSO |
| Community | Ukraine/global narrative | NGO pack pilot | ambassador/moderated submissions |
| Trust | report/quarantine/correction | appeals/transparency | staffed moderation/research governance |

## Kill criteria

Remove or redesign a feature if it makes users more dependent on AI authority, rewards certainty/virality over evidence, lacks safe ground truth/licensing, requires unstaffed moderation, harms accessibility/privacy, or cannot be demonstrated reliably before the deadline.
