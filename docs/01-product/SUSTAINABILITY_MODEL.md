# Sustainability model

## Public-benefit core

Keep core learner missions and verification methods accessible. Avoid monetizing fear, political profiling or selling learner data.

## Growth paths

- grants/UNESCO/EU/education/digital-resilience support;
- institutional implementation/training/support;
- reviewed custom/local scenario packs;
- research partnerships and evaluation;
- optional hosted organization features while open format remains portable.

These are possibilities, not current partnerships/revenue.

## Sustainability dimensions

- Content: reviewed contributors, expiry/corrections, localization.
- Technical: managed services, portable schemas/adapters, cost caps, open standards.
- Operational: named owners, moderation/support, incident/release process.
- Financial: per-active-learner/AI cost measurement and grant/institution model.
- Impact: transfer/retention/calibration, not downloads/XP alone.
- Governance: youth/community participation plus expert review and appeals.

## Unit-cost levers

Curated offline packs, provider metadata cache, deterministic hints, model routing/caps, stateless autoscaling, aggregate analytics and no custom detector training.
