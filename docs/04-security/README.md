# Security, privacy and AI safety

It is impossible to guarantee prevention of every cyberattack. Our measurable promise is defense in depth: reduce likelihood/impact, detect quickly, respond safely, recover, and learn.

## Standards baseline

- [NIST CSF 2.0](https://www.nist.gov/cyberframework): Govern, Identify, Protect, Detect, Respond, Recover.
- [NIST SSDF](https://csrc.nist.gov/Projects/ssdf): secure development lifecycle.
- [OWASP ASVS](https://owasp.org/www-project-application-security-verification-standard/): web/API controls.
- [OWASP API Security](https://owasp.org/API-Security/): authorization, consumption and API abuse.
- [OWASP MASVS](https://mas.owasp.org/MASVS/): Flutter/mobile storage, auth, network, platform, code, resilience, privacy.
- [OWASP Top 10 for LLM Applications](https://genai.owasp.org/): prompt injection, data leakage, excessive agency and model risks.
