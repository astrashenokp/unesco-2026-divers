## Submission week

| Day | Integrated outcome | Primary owners |
|---|---|---|
| D1 | contracts frozen, Flutter shell, API/DB skeleton, two mission fixtures | all |
| D2 | vertical slice through prediction/evidence/conclusion/receipt | frontend + platform |
| D3 | bounded coach + evals + offline fallback; visual system | AI + frontend |
| D4 | security/accessibility/E2E/load pass; micro-pilot | quality + all |
| D5 | fixes, proposal, demo recording/subtitles, evidence appendix | all |
| D6 | final rehearsal and early submission; confirmation archived | all |

## First 30 days

Harden auth/privacy; 12–20 reviewed missions; citation adapter; boosters; CI/CD/observability; pilot protocol; deletion/export; stakeholder interviews.

## 90 days

Education pilot, pack authoring/review workflow, classroom mock-to-beta, offline packs, accessibility audit, D7/D30 learning study, partner discovery.

## 12 months

Validated learning model, multilingual reviewed packs, institution workspaces, sustainable content governance, external security/research review. Platform scope is earned by evidence, not assumed.

## Milestone exit rule

Each milestone has working software, contract evidence, safety/quality evidence, measurable user outcome, next risks and explicit things not built.
