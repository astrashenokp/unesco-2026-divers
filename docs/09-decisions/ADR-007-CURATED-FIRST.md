# ADR-007: Curated cases before unrestricted URL/upload

Status: Accepted — 2026-08-10

## Decision

P0 uses reviewed bundled cases. Live academic provider can be P1 behind fixtures/fallback. Arbitrary URL/media upload, public UGC and chat are deferred until SSRF/parser/moderation/privacy controls and staffing pass.

## Rationale

Improves demo determinism, evidence quality, licensing and child/content safety while preserving the learning thesis.

## Consequences

The pitch must not imply universal live fact checking. Roadmap remains credible with explicit security gates.
