# Submission checklist

## 7 days before

- [ ] Re-open the official call and copy every field, word limit, eligibility rule, deadline, timezone, and attachment rule into a private working checklist.
- [ ] Confirm team and participant eligibility.
- [ ] Freeze the feature list represented in the application.
- [ ] Assign every quantitative claim an evidence ID.
- [ ] Clear rights for screenshots, media, fonts, music, datasets, and scenario content.
- [ ] Obtain consent for any identifiable participant quote, photo, voice, or video.
- [ ] Complete accessibility and safety walkthroughs.

## 48 hours before

- [ ] Export the final text to a stable local format.
- [ ] Check word and character limits in the actual form.
- [ ] Test every public URL in a signed-out browser.
- [ ] Ensure demo access does not require a judge to request permission.
- [ ] Record a backup demo and capture key screenshots.
- [ ] Remove secrets, personal data, debug panels, and private analytics.
- [ ] Reconcile proposal, deck, demo, README, and evidence appendix.

## Final content review

- [ ] The first paragraph states user, problem, and outcome.
- [ ] The solution is not described as a universal detector or cure.
- [ ] Current results and future targets use different language.
- [ ] Risks and limitations are explicit.
- [ ] Citations point to primary or authoritative sources where available.
- [ ] No statistic is cited to a search result, AI answer, or unsourced slide.
- [ ] The requested support is concrete.

## Final technical review

- [ ] Pinned demo build loads on the target device and network.
- [ ] Critical path works without a live third-party AI call.
- [ ] The backup video has captions and audible narration.
- [ ] Links use HTTPS and do not expose internal systems.
- [ ] Repository visibility and license match the team’s decision.

## Submission moment

- [ ] Submit at least several hours before the deadline.
- [ ] Save the confirmation page, timestamp, submission ID, and exact submitted files.
- [ ] Record the commit/build identifier represented by the submission.
- [ ] Do not edit public evidence after submission without preserving the submitted snapshot.
