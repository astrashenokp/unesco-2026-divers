# User research and pilot operations

This folder supports responsible discovery and validation. It is operational guidance, not legal or research-ethics advice. Work involving minors, sensitive topics, schools, or publication may require institutional, safeguarding, and jurisdiction-specific review.

## Minimum workflow

1. State the research question and decision it will inform.
2. Recruit only the audience needed to answer it.
3. Use the [participant information and consent template](PARTICIPANT_INFORMATION_AND_CONSENT_TEMPLATE.md).
4. Run the [interview](USER_INTERVIEW_SCRIPT.md) or [pilot protocol](USABILITY_PILOT_PROTOCOL.md).
5. Capture observations without unnecessary personal data.
6. Report findings and limitations using the [pilot report](PILOT_REPORT_TEMPLATE.md).
7. Update the decision log and evidence appendix.

Before collecting any participant information, complete the [research data management plan](DATA_MANAGEMENT_PLAN.md).

## Non-negotiables

- Participation is voluntary and withdrawal has no penalty.
- Do not collect data “just in case”.
- Do not use real harmful content when a safe synthetic or redacted example answers the question.
- Never record voice, video, screen, or identifiers without explicit permission.
- Separate contact details from research responses.
- Report small-sample findings as directional, not representative.
