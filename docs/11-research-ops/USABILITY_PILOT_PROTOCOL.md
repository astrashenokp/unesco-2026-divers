## Measures

Separate measure classes:

| Class | Example | What it can support |
|---|---|---|
| Usability | task completion, critical error, help level | whether the flow can be used |
| Engagement | voluntary completion, return intention | whether the experience holds attention |
| Immediate learning | pre/post strategy selection | short-term change under study conditions |
| Transfer | new-format scenario performance | application beyond trained examples |
| Retention | delayed task | persistence over time |
| Safety | distress, report use, harmful amplification | whether safeguards work |

Do not infer retention or real-world behaviour from immediate completion.

## Core tasks

1. Complete a scenario containing authentic media in misleading context.
2. Identify the most relevant source/evidence.
3. Update confidence and explain why.
4. Find help, content warning, or reporting controls.

## Success thresholds

Set before data collection, for example:

- at least [X/Y] participants complete the core loop without moderator instruction;
- no participant is forced to view content after choosing to stop;
- at least [X/Y] can explain that feedback is evidence-based, not absolute truth;
- all critical safety failures trigger a stop-ship decision regardless of average score.

## Procedure

1. Verify consent and participant code.
2. Collect the minimum pre-task measure.
3. Read neutral task prompts.
4. Record behaviour, errors, help level, and quotes only as consented.
5. Run debrief and distress check.
6. Store notes in the approved location and delete temporary recordings on schedule.

## Analysis plan

- Report denominators, missing data, and exclusions.
- Distinguish observation from interpretation.
- Group issues by severity and affected outcome.
- Compare against predeclared thresholds.
- Document changes made and unanswered questions.
- Never publish identifiable raw notes.

## Stop conditions

Stop or pause the study for consent ambiguity, unexpected distress, exposed personal data, unsafe content, broken withdrawal controls, or a prototype behaviour that invalidates the planned task.
