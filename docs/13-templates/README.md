# Operational templates

These templates make decisions and coordination reproducible without defining engineering roles.

- [Project board](PROJECT_BOARD.md)
- [Meeting notes](MEETING_NOTES_TEMPLATE.md)
- [Decision proposal](DECISION_TEMPLATE.md)
- [Release notes](RELEASE_NOTES_TEMPLATE.md)
- [Retrospective](RETROSPECTIVE_TEMPLATE.md)

Copy a template into the team’s chosen work system, assign a stable ID, and link back to evidence or source documents. Do not store secrets, participant data, or confidential partner terms in a public board.
