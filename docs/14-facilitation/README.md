# Facilitation kit

This kit makes Evidence Gym usable as a supervised learning activity without requiring facilitators to invent safety or pedagogy rules during the session.

1. Read the [facilitator guide](FACILITATOR_GUIDE.md).
2. Adapt the [45-minute workshop](WORKSHOP_45_MIN.md).
3. Introduce the [discussion norms](SAFE_DISCUSSION_NORMS.md).
4. Use the [debrief bank](DEBRIEF_QUESTION_BANK.md).
5. Draft new material only through the [scenario template](SCENARIO_AUTHORING_TEMPLATE.md) and full content review.

Do not use this public kit as a substitute for local safeguarding policy, educator approval, or subject-matter review.
